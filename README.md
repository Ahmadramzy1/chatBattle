# Chat Battle ⚔️

یک سایت مستقل برای مسابقه حذفی ویدیوهای ارسال‌شده در چت Kick.

**آدرس سایت پس از فعال‌سازی GitHub Pages:** https://ahmadramzy1.github.io/chatBattle/

## راه‌اندازی GitHub Pages

1. از **Settings → Pages** وارد تنظیمات ریپو شوید.
2. در **Build and deployment**، گزینه **Deploy from a branch** را انتخاب کنید.
3. **main** و **/(root)** را انتخاب و **Save** کنید.
4. منتظر پیام «Your site is live» یا موفقیت workflow به نام pages build and deployment بمانید.

فایل شروع سایت `index.html` است و تمام کدهای ضروری داخل خود این فایل هستند؛ Build، npm و سرور لازم نیست.

## امکانات

- دریافت لینک و پیام رأی از چت Kick با اتصال Pusher مشابه [instaQ](https://github.com/Ahmadramzy1/instaQ).
- رقابت حذفی 16، 24، 32 و 48 ویدیویی؛ ظرفیت‌های خاص با BYE مدیریت می‌شوند.
- محدودیت لینک برای هر کاربر و پنهان‌کردن اسم فرستنده در رابط مسابقه تا پایان.
- شمارش پیام دقیق `1` یا `2` در بازه رأی‌گیری، تایمر و شمارنده متحرک.
- پخش ویدیوهای YouTube/TikTok از iframe با اندازه متناسب با کادر.
- Instagram: تلاش برای یافتن منبع قابل‌پخش در HTML5 با تایم‌لاین، پنج ثانیه جلو/عقب، سرعت، قطع صدا و فول‌اسکرین؛ در صورت عدم امکان، نمایش Embed رسمی متناسب با کادر.
- دکمه **باز کردن در سایت اصلی** همیشه زیر هر ویدیو.
- نتیجه پایانی با رتبه‌بندی، تصویر بندانگشتی در منابعی که موجود است و افشای نام کاربران.
- حالت تست بدون چت زنده و ذخیره خودکار وضعیت در localStorage.

## محدودیت‌ها

- تأیید اتصال زنده Kick هنوز نیاز به آزمون روی کانال واقعی دارد. اتصال Pusher غیررسمی است و به سرویس‌های بیرونی وابسته است.
- نمایش همه ویدیوهای YouTube در iframe تضمین نمی‌شود؛ مالک بعضی ویدیوها Embed را غیرفعال کرده است. روی HTTPS خطای 153 ناشی از بازکردن مستقیم `file://` کمتر رخ می‌دهد.
- استخراج ویدیوی Instagram به محدودیت‌های دسترسی، CORS و در دسترس بودن سرویس‌های واسط وابسته است؛ هنگام شکست، Embed و لینک سایت اصلی جایگزین می‌شوند.
- داده‌ها در همان مرورگر ذخیره می‌شوند و بین دستگاه‌ها همگام نمی‌شوند.
- GitHub Pages فقط میزبان استاتیک است؛ برای رأی‌گیری تأییدشده از سمت سرور و جلوگیری قوی از دستکاری رأی، در نسخه‌های بعدی بک‌اند لازم است.
